# IDEA Santander — web

React + Vite + Tailwind v4 + Motion.

    npm install
    npm run dev

Todo el texto (servicios, misión, visión, preguntas, WhatsApp, correo) está en `src/data.js`.
Pendientes: tu foto en `public/` (ver comentario en Nosotros.jsx), link de Instagram y de tu portafolio.

Publicar: sube la carpeta a GitHub → vercel.com → Add New Project → Deploy →
Settings → Domains → ideasantander.com (registros DNS en Cloudflare con nube gris).
